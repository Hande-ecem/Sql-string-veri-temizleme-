SQL String, NULL Handling & Marketing Analytics

Bu projede, Facebook Ads ve Google Ads verileri kullanılarak SQL ile veri birleştirme, string ifadeler üzerinde işlem yapma ve eksik (NULL) değerlerin yönetimi üzerine çalışılmıştır.

Projede;

Birden fazla tablodan veri CTE (Common Table Expression) kullanılarak birleştirildi.
Facebook ve Google reklam verileri üzerinde JOIN işlemleri gerçekleştirildi.
URL içerisindeki UTM parametreleri string fonksiyonları ve düzenli ifadeler (Regular Expressions) kullanılarak ayrıştırıldı.
LOWER, SUBSTRING gibi string fonksiyonları kullanılarak metin verileri işlendi.
NULL ve eksik değerler CASE ve COALESCE kullanılarak yönetildi.
spend, impressions, clicks, leads ve value gibi reklam performans metrikleri analiz edildi.
CTR, CPC, CPM ve ROMI gibi pazarlama performans göstergeleri SQL ile hesaplandı.
Sıfıra bölme hatalarını önlemek amacıyla CASE ifadeleri kullanıldı.
Kampanya bazında günlük reklam performansı analiz edildi.

Kullanılan Teknolojiler:
SQL · CTE · JOIN · CASE · COALESCE · Regular Expressions · String Functions · Marketing Analytics
